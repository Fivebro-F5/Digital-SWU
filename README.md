# 数字西大

基于 Web 的西南大学数字校园游戏化平台。项目目标是融合校园导览、社交互动和校园服务，逐步建设可探索、可交互、可扩展的虚拟校园。

当前仓库处于规划阶段，尚无可运行的应用代码。首期以一个局部校园场景打通前端、后端、数据库、插件和多人同步的技术链路；其他业务模块在后续迭代实现。
