# 数字西大 · 24 子图地形地图 V3

- 结构：6 个大区（2×3）
- 子图：每个大区 2×2，共 24 张 TMX / JSON
- 规格：每图 100×74 格，每格 16×16 像素
- 角色：建议 48×48 像素，对应 3×3 瓦片

## 大区划分
1. A 教学组团：25教、伴月楼、26/27/28教
2. B 杏园与第二运动场：杏园、杏园食堂、保卫处、第二运动场
3. C 北樟林与北区图书馆：北樟林、弘文楼（北区图书馆）、北区校医院、篮球场
4. D 图书馆 / 李园 / 八教：中心图书馆、崇德湖、李园、敬德楼（第八教学楼）、中心体育馆、第三运动场
5. E 一号门 / 行署楼：含弘门、雕像广场、行署楼A/B、行政广场、芳樟林、一运西口
6. F 美术学院 / 第一运动场：至美楼（美术学院）、第一运动场、篮球场

## 工程内容
- `maps/*.tmx`：Tiled 可直接打开的地图
- `maps/*.json`：与 TMX 对应的 Tiled JSON
- `assets/ground_tiles_16.png`：共用地形瓦片图集
- `map_connections.json`：大区与子图的连接关系
- `previews/master_layout_24.png`：六大区总关系图
- `previews/scene_connections_24.png`：24 子图切换关系图
- `previews/all_24_scenes_contact_sheet.png`：全部地图总览

## 说明
- 当前版本只做地形地图、建筑预留地和地标中文标注。
- 树木、路灯、建筑立面和实体碰撞体后续再单独制作。
- 预留地默认可走；以后替换成建筑物时可再加碰撞。
- 本工程根据西南大学官方页面与用户提供示意图做游戏化分区，适合数字校园项目，不是精确测绘图。
