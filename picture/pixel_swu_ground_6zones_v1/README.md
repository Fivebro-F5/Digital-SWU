# 像素西大 · 一号门周边六区【纯地形地图 v1】

> **范围**：从西南大学含弘门（一号门）出发制作 00～05 六个连通游戏场景。这里的地图是依据官方资料确定主要空间关系、**为游戏而简化的概念底图**，不是百度地图、卫星图或无人机测绘图的精准转绘，不可用于真实导航。
>
> **这一版故意只交付“地形”**：地面、主路、辅路、台阶、广场、可行走绿化、建筑地面占地预留。**不画建筑立面、树、路灯、围栏，不给其添加碰撞。**

## 二、尺寸规则（已经统一）

| 项目 | 实际值 |
| --- | --- |
| 地图基础瓦片 | **16×16 像素** |
| 人物素材 | **48×48 像素**，相当于 3×3 瓦片 |
| 每区矩形尺寸 | **100×74 瓦片** |
| 每区原始像素尺寸 | **1600×1184 像素** |
| 行署路主线铺装宽度 | 大约 16～18 个瓦片（256～288 像素） |
| 主要场景过渡口 | 南北：17瓦片宽；东西：15瓦片高（全图一致） |
| 人物物理碰撞建议 | **22×14 像素**脚底碰撞盒，48×48 是显示图片，不是整张头发都参与撞墙 |
| 游戏世界坐标原点 | **00 一号门通道中心，脚底点 = 世界(0,0)**；世界向北 y 为负 |

**注意：**角色图片 48×48 不要求把地图每格也改成48；采用16像素地块更方便画弯道、台阶及草地边缘。三格等于一角色，这两者完全兼容。地图按照 1:1 的像素显示在内部画布，再使用最近邻整数放大。

## 四、TMX 的图层

每张 TMX 都是 **4 个纯瓦片层 + 3 个编辑用对象层**：

1. `Ground`：基础草地。
2. `Landscape`：同样可以踩的地被、花草纹理。
3. `Roads`：石板路、砂路、广场、台阶、人行道、车行铺装。
4. `BuildingPads`：建筑地面占地预留；仅是地面颜色，不是建筑物或碰撞。
5. `BuildingSlots`：**默认隐藏**的矩形预留区域。属性包含 `display_name`、`confidence`、`future_collision`、`currently_walkable`。
6. `Portals`：**默认隐藏**的换场触发矩形。属性 `direction`、`target_scene`、`target_portal`、`spawn_x_px`、`spawn_y_px`。
7. `Spawn`：**默认隐藏**的人物出生点，定义的是脚底点，不是图片左上角。

没有 Collisions 图层，是刻意的。下一阶段把建筑/树木/灯具实体放进去后，再给对象添加碰撞区域；当前所有地面包括绿化都可行走。

## 五、Tiled 怎么打开和编辑

1. 下载并**完整解压 ZIP**，保留目录结构。
2. 安装免费 Tiled：https://www.mapeditor.org/ 。
3. 在 Tiled 内打开 `maps/00_hanhong_gate.tmx`。同时打开 `maps/04_memorial_steps.tmx`，检查上下边缘道路对齐。
4. `assets/ground_tiles_16.png` 是单张共用瓦片图集，**不要移动它**，否则相对路径失效。
5. 在地图左侧的瓦片集里选择一个 16×16 瓦片，选择 `Roads` 层就可修改路径；切到 `BuildingPads` 可以编辑建筑预留铺装；`BuildingSlots` 可打开可见以调整预留区域矩形。
6. 如果只修改某一地图，使用 `File → Export As...` 可以重新导出对应 Tiled JSON。压缩包里的 `maps/*.json` 已经按 Tiled 标准格式导出。

## 六、快速试玩六张地图

在解压后的项目根目录打开命令行：

```bash
python -m http.server 8000
```

浏览器访问 `http://localhost:8000/walk_test.html`，使用 WASD 或方向键移动，Shift 加速，H 查看预留区和出口。走到路的边界自动切换地图；也可以用右侧按钮直接切地图。

这个页面使用预览地形 PNG 验证换场，不是使用 Phaser 实时解析 TMX；正式项目应该让前端读取 JSON 的图层和 `Portals`，生成换场逻辑。测试页面不代表已经加入实际门禁、建筑碰撞或角色动画。

## 七、接入前端的关键字段

- 每张 `maps/*.json` 都是标准 Tiled JSON：`layers[].data` 为平铺的瓦片 GID，`tilesets[].image` 指向 `../assets/ground_tiles_16.png`。
- `map_connections.json` 是额外的**跨场景导航 manifest**，比逐个解析 `Portals` 更容易联调。
- 换场触发时，把玩家脚底点设置成对应 `arrival_feet_px`，别把 `48×48` 图片左上角设置为脚底。
- 每张地图本地 pixel 坐标范围是 x=0..1600, y=0..1184；`world_top_left_px` 给出了拼成大地图时的全球偏移。
- **世界原点**定义在 00 场景含弘门中心通道的 `(50×16,57×16)=(800,912)` 像素。世界坐标可以取 `global=local+world_top_left_px`。
- 保留 `id` 字符串 `00`～`05`，不要自动转 int 导致 `00` 变成 `0`。
