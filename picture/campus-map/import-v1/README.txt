直接读取 entities.json.features。单位为底图像素，原点左上；坐标为本地平面，勿作为经纬度投影。每个 Polygon 第一环为外壳，后续为孔洞，按 evenodd 填充。boundary 为容器，应先绘制；其余按类型分层。不同图层允许重叠。ID 在本版本内固定。导入时按 ID 与 id-table.csv 关联。
轮廓按 JPG 图例颜色、连通区域与文字修补提取。校园范围以连续着色区的外缘估计。道路按连通面分组；水域包括溪流。运动用地包含小球场。空名称表示未核实；碎片、相邻楼合并、细路断点、窄边界和地标漏识别需用 overlay.png 叠图人工复核。面积是导出多边形面积，单位 px²。无比例尺和地理控制点。
