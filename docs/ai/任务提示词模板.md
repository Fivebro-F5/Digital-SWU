# AI 单次任务提示词模板

复制以下模板并填入本次任务信息。填写“未指定”时，AI 应先查看仓库和[待决策事项](../project/待决策事项.md)，对不影响安全或产品边界的细节提出并记录合理选择；关键授权、隐私和产品范围问题应明确列为待决策。

```text
项目：数字西大
任务名称：[一句话描述]
任务背景：[用户问题或需求来源]
目标阶段：[MVP / 后续迭代]
本次范围：[必须实现的功能、入口与受影响模块]
不在本次范围：[明确排除的功能]
输入/依赖：[已有文件、接口、数据来源、授权情况]
预期交付：[代码、迁移、文档、测试或演示]
验收标准：[可观察的成功条件、错误场景与权限规则]
约束/偏好：[如有]

请先阅读 AGENTS.md 及其引用的项目文档，检查实际仓库状态，再完成任务。不要将待定方案视为既定事实。变更插件契约、HTTP/Socket.IO 接口、数据库或地图坐标时，说明兼容与迁移影响并更新文档。运行与本次改动相关的验证；报告真实结果及剩余问题。
```

## MVP 首个实现任务示例

```text
任务名称：建立 MVP 应用骨架及插件最小闭环
目标阶段：MVP
本次范围：按项目约束建立前端、后端和数据库工程；实现可注册、启动、发现服务和报告错误的最小插件核心；提供一个示例插件验证通信链路。
不在本次范围：完整校园地图、聊天、教务对接和社区功能。
输入/依赖：仓库文档；具体包管理器、目录布局和库版本尚待选择并记录。
预期交付：可启动的工程、插件契约、示例插件、必要测试、初始化说明和决策记录。
验收标准：开发环境能启动；示例插件可通过契约注册并提供服务；缺失依赖或启动失败有可定位错误；类型检查、静态检查和相关测试通过。
```
