# 单人游戏原型

## 含弘门场景

当前 Phaser 原型使用 [SWU_Gate1_Hanhong.tmx](../../picture/swu_gate_project/SWU_Gate1_Hanhong.tmx)。地图参考含弘门实景绘制，路线、距离和台阶后的建筑为游戏示意。

运行 `npm run dev:web`，打开终端显示的地址。用 WASD、方向键或页面方向按钮四向移动，按住 Shift 疾跑。靠近含弘门、雕像花园、景观台阶、示意建筑或说明牌后，按 E、空格或页面的互动按钮查看介绍。

## 地图与坐标

地图大小为 96 × 84 格，每格 16 × 16 像素。角色脚底从 TMX 的 `Spawn/player_start` 原坐标出生，每次移动一格。移动前检查整段轨迹是否穿过 `Collisions` 层的矩形。页面显示游戏像素坐标。

在 Tiled 编辑并保存 TMX 即可更新地图。当前读取器支持正交方格、CSV 瓦片层、内嵌地形图集与独立图片、矩形碰撞和对话对象，以及点状出生点。图片通过 TMX 的相对路径从同目录的 `assets` 加载。解析在 `gateMap.ts`，移动判定在 `campus.ts`，渲染和小鸟动画在 `CampusScene.ts`。

本场景用于本地单人预览。多人位置裁决及与真实校园地理坐标的映射属于后续工作。
