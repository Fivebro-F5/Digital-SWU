# 单人游戏原型

## 含弘门场景

当前 Phaser 原型从 [00 含弘门入口](../../picture/pixel_swu_ground_6zones_v1/maps/00_hanhong_gate.tmx) 出发，可经边界道路双向往返 01 校门外衔接区、02 东侧樟林、03 西侧樟林和 04 雕像花园。04 雕像花园北口与 05 行署路南口双向连通。

运行 `npm run dev:web`，打开终端显示的地址。用 WASD、方向键或页面方向按钮四向移动，按住 Shift 疾跑。画面以外的界面为开发调试台，显示角色脚底与渲染坐标、朝向、速度、室外维度、当前地图分区、地图对象与碰撞数量、纹理资源数和 Phaser 实时帧率；数据按约 50 毫秒刷新。

## 地图与坐标

每区大小为 100 × 74 格，每格 16 × 16 像素。角色首次从 00 的 `Spawn/player_start` 出生，目前为 `(800, 896)`，每次移动一格。东西出口的 y 范围为 496–720，南北出口的 x 范围为 688–928，含端点。在出口沿向外方向移动会出现在相邻地图的对侧边界，并保留沿边界的坐标。页面显示当前区域和该区域的像素坐标。

在 Tiled 编辑并保存 TMX 即可更新地图。地形图集位于地图目录的同级 `assets`。解析在 `gateMap.ts`，移动判定在 `campus.ts`，渲染、小鸟动画与只读调试快照在 `CampusScene.ts`。资源数分别表示当前已加载纹理数及工程声明的图片路径数，不代表显存占用；速度显示当前移动指令对应的像素每秒，静止时为零。游戏网格坐标不等于真实校园地理坐标。

本场景用于本地单人预览。多人位置裁决及与真实校园地理坐标的映射属于后续工作。
