# 单人游戏原型

此原型用于优先验证 Phaser 场景、角色移动与地点交互，属于[项目概述](数字西大-项目概述.md)的 MVP 开发过程，不代表完整 MVP 验收。

## 启动与操作

在仓库根目录安装依赖后运行 `npm run dev`（同时启动 API）或 `npm run dev:web`（只启动游戏），打开终端输出的地址。用 WASD、方向键或页面上的方向按钮移动。靠近建筑旁的黄色标记后，按 E 或点击“查看地点”弹出地点介绍。可运行 `npm test` 验证地图边界、建筑碰撞与交互范围。

## 数据与实现边界

- 12×12 等距地块、道路、四座建筑和入口标记由程序绘制；建筑名称与位置是虚构示意，不对应已核实的西南大学地理数据。
- 玩家位置目前只保存在浏览器内存。移动使用场景网格坐标，碰撞和交互判定位于 `apps/web/src/game/campus.ts`，Phaser 渲染位于 `apps/web/src/game/CampusScene.ts`。
- API 健康状态只是连通性提示。当前没有登录、服务端权威移动、Socket.IO 多人同步、PostGIS 地点查询或地理坐标转换，因此不能把原型位置当成真实导航结果。
- 后续接入 Tiled/Phaser Editor 地图时需替换示意地块和建筑数据，建立经校对的控制点、地理坐标与游戏坐标映射，并由服务端验证移动和地点交互。
