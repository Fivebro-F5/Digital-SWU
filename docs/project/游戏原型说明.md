# 单人游戏原型

## 当前方向

根据 2026-11-05 用户的最新要求，当前可玩原型改为类 GBA 时代的俯视角 2D 游戏表现。这里的“类”指低分辨率像素画面、网格移动和简洁对话框；角色、建筑、地块及配色均由本项目原创程序绘制，不使用宝可梦角色、地图、音乐或其他受保护素材。此变更覆盖此前原型中的等距视角、旋转缩放、临时平移及高低差表现。项目概述仍是长期需求基线，最终产品是否采用 2D 表现需另行决策。

## 启动与操作

安装依赖后运行 `npm run dev` 或 `npm run dev:web`，打开终端显示的地址。组合 WASD、方向键或页面方向按钮可八方向逐格移动；斜向移动不能穿过障碍角。按住 Shift 疾跑；面向实体按 E、空格或页面互动按钮。点击实体可直接查看或触发其交互。所有建筑门统一通过站在门外并向门内行进触发，室内出口同理，无须按 E。画板逻辑分辨率为 384×240；空间足够时按整数倍放大，镜头紧跟整数像素位置以减少移动抖动。

## 示例玩法

| 对象 | 当前行为 |
|---|---|
| 通行卡 | 在中央道路拾取；拾取后可进入图书馆。 |
| 图书馆 | 持卡站在门外，向上移动进入独立室内场景；无卡时提示条件未满足。 |
| 教学楼、食堂、活动中心 | 站在门外向上移动进入室内；活动中心楼梯可按 E 切换 1F～3F。 |
| NPC、Bot、校园猫、单车、路灯 | 提供点击或面向互动范例；路灯可切换状态。 |
| 室内出口 | 在出口前向下移动返回校园。 |

室内、楼层、地块与建筑位置均为虚构示意，尚未使用可靠的真实校园地理数据。单车尚不能骑乘，NPC 暂无真实对话系统；Bot 和动物只提供交互示例。角色坐标和通行卡状态仅保存在当前浏览器运行时。

## 技术与边界

地图与交互规则位于 `apps/web/src/game/campus.ts`，Phaser 场景和原创程序绘制素材位于 `apps/web/src/game/CampusScene.ts`。场景坐标是游戏网格坐标，不是经纬度。API 健康状态只显示连通性；登录、服务端权威移动、多人同步、PostGIS 地点查询和真实校园服务尚未实现。后续若接入真实地图，应先核定数据授权与控制点，并在服务端验证移动和交互。
