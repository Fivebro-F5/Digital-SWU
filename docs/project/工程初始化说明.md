# 工程初始化说明

记录 2026-11-04 的工程选择。依据[项目概述](数字西大-项目概述.md)建立最小技术骨架；并不代表 MVP 业务已完成。

## 目录

| 路径 | 用途 |
|---|---|
| `apps/web` | Vue 3 + Vite 页面与 Phaser 场景入口 |
| `apps/api` | NestJS HTTP 入口、Drizzle 模型及迁移配置 |
| `packages/contracts` | 前后端共享的 TypeScript 类型 |
| `infra` | 本地开发使用的 PostGIS Compose 配置与扩展初始化 SQL |
| `docs` | 需求、约束、架构与 AI 指引 |

## 技术选择

- 包管理：npm workspaces + 根目录 `package-lock.json`，使用 `npm ci` 复现依赖。
- 运行时：Node.js 24.15+。选择该下限以满足所用 Nest CLI 的 Node 要求。
- Web：Vue 3、TypeScript 6、Vite 8、Phaser 4。Phaser 4 是初始化时的版本选择，地图制作前需验证 Tiled 和 Phaser Editor 的资源兼容性。
- API：NestJS 12、TypeScript 6；保留 Socket.IO 依赖，但尚未开放实时网关。
- 数据：PostgreSQL/PostGIS、Drizzle ORM/Kit、`pg`。当前仅定义 `places` 空间表模型，服务启动不连接数据库。首次创建本地数据库时由初始化 SQL 启用 PostGIS，再生成并执行 Drizzle 迁移。
- 文件：MinIO SDK 与环境变量入口已配置，尚无上传接口或默认容器。可用服务镜像及部署方式需在上传功能开发前核定。
- Tiled 与 Phaser Editor 为外部地图编辑工具，不由 npm 安装。Redis 仅为后续适配预留方向，当前未安装。

具体补丁版本以锁文件为准。开发环境 Compose 仅用于本机验证，不决定生产部署架构。`.env.example` 中的凭据只用于本地开发，不能用于对外环境。

## 命令

在仓库根目录运行：

| 命令 | 作用 |
|---|---|
| `npm ci` | 按锁文件安装依赖 |
| `npm run dev` | 同时启动 NestJS 和 Vite，Ctrl+C 同时停止 |
| `npm run dev:debug` | 同时启动并开放本机 API 调试端口 9229 |
| `npm run dev:api` | 启动 NestJS 开发服务，默认 `127.0.0.1:3000` |
| `npm run dev:web` | 启动 Vite 开发服务；`/api` 代理到本地 API |
| `npm run typecheck` | 检查全部 workspace 的类型 |
| `npm test` | 运行已建立的原型规则测试 |
| `npm run build` | 构建 API 和 Web |
| `docker compose -f infra/compose.yaml up -d` | 启动本地 PostGIS；需自行安装 Docker Compose |
| `npm run db:generate` | 根据 Drizzle 模型生成迁移 |
| `npm run db:migrate` | 应用迁移；需先启动数据库并配置 `.env` |

首次运行前复制 `.env.example` 为 `.env`。本地数据库端口为 5432；如本机端口冲突需调整 Compose 与环境配置。`MINIO_*` 变量是未来接入的示例入口，目前无默认 MinIO 服务。数据库尚无真实校园地点数据。

## 当前边界与后续任务

前端已有[单人游戏原型](游戏原型说明.md)及 API 连通状态；API 只提供 `GET /api/health`。真实地图、插件微内核、注册登录、Session、RBAC、坐标校准、多人同步、上传及校园数据接入都尚未实现。健康检查仅表示 API 进程可用，不代表数据库或 MinIO 健康。

下一步应优先实现插件核心及契约测试、身份会话、局部场景和坐标映射，再接入经过权限验证的 Socket.IO。实现业务接口时补充测试、静态检查和 CI；当前仅有类型检查与构建脚本。
