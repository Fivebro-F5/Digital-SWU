# 启动与调试

## 一键入口

在 Windows 双击仓库根目录的 `启动开发.cmd` 或 `启动调试.cmd`。脚本切换到仓库目录；依赖缺失时先运行 `npm ci`，随后同时启动 Web 和 API。首次安装依赖需要可访问 npm 仓库。

跨平台终端在仓库根目录运行 `npm ci`，再运行 `npm run dev` 或 `npm run dev:debug`。两个命令都由 `scripts/dev.mjs` 统一启动服务并带 `[WEB]`、`[API]` 日志前缀。任一服务异常退出时，启动器停止另一服务；按 Ctrl+C 也会停止两个服务。

| 模式 | Web | API | Node 调试器 |
|---|---|---|---|
| `npm run dev` | `http://127.0.0.1:5174` | `http://127.0.0.1:3000` | 不开放 |
| `npm run dev:debug` | `http://127.0.0.1:5174` | `http://127.0.0.1:3000` | `127.0.0.1:9229` |

调试 API 时，先运行调试模式，再在 VS Code 中选择“附加到数字西大 API”并按 F5；其他编辑器可用 Node.js **Attach** 连接 `127.0.0.1:9229`。浏览器端可使用浏览器开发者工具调试 Vue 和 Phaser。调试端口只监听本机，不应改成对外开放。

Web 端口固定为 5174，已占用时 Vite 会报错，避免打开错误的服务。API 端口默认为 3000，若通过 `.env` 修改 `API_PORT`，还需同步修改 `apps/web/vite.config.ts` 中的代理地址。

当前游戏原型不依赖数据库。需要验证 PostGIS 迁移时，按[工程初始化说明](工程初始化说明.md)额外启动 Docker Compose 并设置 `.env`。
